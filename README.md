# 🛍️ Customer Shopping Behavior Analysis

A data analytics project focused on analyzing **customer shopping behavior and purchasing patterns** to uncover meaningful business insights. The project uses **Python, SQL, and Power BI** to explore customer demographics, sales performance, product preferences, and purchasing trends.

### 🔍 Key Analysis

* Customer demographics and purchasing behavior
* Sales and revenue analysis
* Product and category performance
* Customer segmentation and trends
* SQL-based business analysis
* Interactive Power BI dashboard for data visualization

### 🛠️ Tools & Technologies

**Python | Pandas | NumPy | SQL | Power BI | Excel**

### 🎯 Objective

To transform customer transaction data into **actionable business insights** that can support data-driven decision-making.
